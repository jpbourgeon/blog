# editorial-plan

Read `AGENTS.md`, both editorial standards, the author's decisions, relevant
sources and the main Capture when available. For a revision, read the published
FR/EN text and the reference plan if it exists.

Build a plan precise enough for another context to draft from it. State the
thesis, intended reader and author's perspective. Explain what each section
contributes, how it follows the preceding material and what it prepares.
Locate arguments, objections, examples, sources and any figure that improves
understanding. Distinguish facts, hypotheses, decisions and open questions.
Keep sources verifiable and label gaps that affect the composition.

Express the author's point of view in outline form. Leave final prose and
stylistic choices to drafting. Reference the Capture and sources where they
carry decisions or evidence. Record the composition here and reconcile material
decisions in the Capture when one is maintained.

Submit the proposed composition to the author before full drafting when the
plan is to guide the text. Only the author's adoption makes it binding on the
composition. Keep unresolved substantive choices open or present alternatives.
Reconcile substantive changes with the author and update affected artifacts
before drafting from them. Drafting and verification can proceed without a plan.

Keep a reference plan at `.42p/design/<identity>/plan.md`. Use
`plan.revision.md` alongside it for work on a published version and keep the
reference plan until authorized promotion of the revision. Use Git for
ordinary iterations before publication. The same planning workflow serves
pages, articles and revisions. Create a plan file only where useful.
